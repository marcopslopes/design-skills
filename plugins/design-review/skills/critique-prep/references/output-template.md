# Critique presenter script — output template

Write this in chat and append the same block to
`projects/<slug>/findings.md` under **Critique presenter script —
YYYY-MM-DD**. Keep it speakable. Default slot: 15–20 minutes.

Do not fill the capture sheet with invented decisions.

```markdown
## Critique presenter script — YYYY-MM-DD

**Slot:** 15–20 min · **Stage:** early concept / mid-fi / final check
**Feedback type:** directional / detailed / one area only
**Figma:** [link] · **Brief:** [link or —]

### 1. Frame (2–3 min — say this out loud)

1. **User goal** — JTBD in the moment (one sentence)
2. **Business outcome** — what this is for, sourced (one sentence)
3. **What I want to learn from this critique** — the actual ask
4. **What's off the table** — so the room doesn't spend the slot there
5. **Journey stage** — plus the counterpart team if the flow crosses

### 2. Walk order

Numbered beats. Prefer 3–6 for a 15–20 min slot.

1. **[Frame / flow name]** — one sentence of what to say → what *not* to dwell on
2. …
3. …

### 3. Feedback ask (paste into the critique sign-up)

One line. Recommended type: directional / detailed / one area only.

> Feedback wanted: …

### 4. Lenses to invite

Subset that matches **this** stage — not the full checklist. See
`lenses.md`. Name each lens in a short clause the presenter can say
("especially usability of the empty state").

### 5. Capture sheet (blank — live notes)

- Key decisions
- Open questions
- Priority changes (**top 3 max**)
- Parked / out of scope

### 6. Sign-up row draft (chat only — do not publish)

| Presenter | Links | Stage | Feedback wanted | Time needed |
|-----------|-------|-------|-----------------|-------------|
| [name] | [Figma] [brief] | [stage] | [one line] | [minutes] |
```
