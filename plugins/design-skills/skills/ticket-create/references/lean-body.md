# Lean ticket body

Copy this structure into every draft. Keep the whole body short enough to
read without scrolling on a laptop (~½ screen).

```markdown
## Why
[2–3 plain lines. Problem + what this ticket is for.]

## In scope
- [Bullet]
- [Bullet]
- [Bullet]

## Out of scope
- [Bullet]
- [Bullet]

## Links
- [Sister ticket / Figma / prior Done ticket — markdown links]

## Done when
[One sentence acceptance.]
```

Optional last line when a project folder exists:

```markdown
Details: `projects/<slug>/findings.md`
```

## Forbidden in the body

- Chat voice ("imo", "I think", "maybe we should")
- Meeting retellings, Trio notes, research dumps
- Full paths to lab prototypes unless the eng ask is literally "build this
  Design Harness page"
- Long out-of-scope essays (max 3 bullets)
