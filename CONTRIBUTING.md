# Contributing to Design Skills

Thanks for helping improve the skills.

The files in this repo are generated from `harness/skills/` in the
[Design Harness](https://github.com/marcopslopes/design-harness). Each new build
replaces them, so pull requests here can't be merged as they are.

## Report a problem or an idea

[Open an issue](https://github.com/marcopslopes/design-skills/issues) when a
skill breaks, gives a weak result, needs a file it can't find, or when a design
workflow you need is missing. Name the skill and the agent you used, and paste
the prompt if you can.

## Change a skill or add one

1. Fork the [Design Harness](https://github.com/marcopslopes/design-harness).
2. Edit `harness/skills/<skill>/SKILL.md`, or add a new skill folder next to the others.
3. Open a pull request in the Harness. Say what design problem the change solves.

The Harness [contributing guide](https://github.com/marcopslopes/design-harness/blob/main/CONTRIBUTING.md)
covers the skill format, trigger phrases, and what makes a good skill. Merged
changes reach this package in the next release.
